## This project

Trainory: the website, a static Astro site with Preact islands and Supabase (auth, Postgres, storage). See `README.md`. The mobile app is `../trainory` (repo `trainory-app`) and shares the Supabase project.

- `CLAUDE.md` is a symlink to this file. Edit this file.
- Every table has a `user_id` column defaulting to `auth.uid()` and one "owner only" RLS policy. New tables must follow the same pattern, in a new file under `supabase/migrations/`.
- Colours are semantic CSS variables in `src/styles/global.css` that flip with the theme, matching the mobile app's `src/constants/theme.ts`. Use `text-ink`, `bg-elevated`, `border-hairline` and friends; do not add `dark:` variants. Lime `primary` is a fill only (with `text-on-primary`); for lime-family text, charts and progress use `accent`.
- In `.astro` files keep text and an adjacent `{expression}` on the same line, or Astro drops the space between them.
- `/app/*`, `/login`, `/signup` and `/reset` are noindex and filtered out of the sitemap in `astro.config.mjs`.
- A signed-in account with no `profiles` row is shown onboarding (`src/app/Onboarding.tsx`); `Gate.tsx` builds the plan from the answers: the starter programme for the goal (`src/data/starter.ts`) and an empty diet plan. No meals or foods are seeded.
- `src/data/food-catalog.ts` is the shared, read-only food list. Picking a food copies it into the account's `foods` (matched by name); foods users create stay in their own list. Exercises work the same way with the exercise catalog.
- `public/exercise-catalog.json`, `public/exercises/` and `src/data/starter-exercises.json` are generated by `scripts/build-exercise-catalog.mjs`. Do not edit them by hand.
- `public/favicon.png`, `public/icons/` and `public/og.png` are generated by `scripts/build-icons.mjs` from `scripts/brand/trainory.svg` (copied from the mobile app). Rerun it if the logo changes.
- localStorage keys start with `trainory-`. The layout's head script moves old `pl-` keys over once.
