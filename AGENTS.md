```

```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## This project

Protein & Lifts: a static Astro site with Preact islands and Supabase (auth, Postgres, storage). See `README.md`.

- `CLAUDE.md` is a symlink to this file. Edit this file.
- Every table has a `user_id` column defaulting to `auth.uid()` and one "owner only" RLS policy. New tables must follow the same pattern, in a new file under `supabase/migrations/`.
- Colours are semantic CSS variables in `src/styles/global.css` that flip with the theme. Use `text-ink`, `bg-elevated`, `border-hairline` and friends; do not add `dark:` variants.
- In `.astro` files keep text and an adjacent `{expression}` on the same line, or Astro drops the space between them.
- `/app/*`, `/login`, `/signup` and `/reset` are noindex and filtered out of the sitemap in `astro.config.mjs`.
- A signed-in account with no `profiles` row is shown onboarding (`src/app/Onboarding.tsx`); `Gate.tsx` builds the plan from the answers. Starter programmes and diets live in `src/data/starter.ts`.
- `public/exercise-catalog.json`, `public/exercises/` and `src/data/starter-exercises.json` are generated by `scripts/build-exercise-catalog.mjs`. Do not edit them by hand.
- `public/icons/` (PWA and Apple touch icons) is generated by `scripts/build-icons.mjs`. Rerun it if the favicon mark changes.
